Gang Beasts Browser

The game is kept in a private GitHub repo, so this page needs a read-only GitHub key once per browser. It downloads the newest build (about 77 MB, once) and keeps it here.

  1. Signed in as AGames21, open New fine-grained token.
  2. Under Repository access choose Only select repositories and pick gang-beasts-browser.
  3. Under Permissions, set Contents to Read-only (nothing else). Generate it and copy it.
